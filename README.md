# Своя игра

Локальная party-версия игры с вопросами, очками, финалом, отменой действий и сохранением прогресса в браузере.

## Локальный запуск

```sh
node server.mjs
```

После запуска открыть:

```text
http://localhost:4173
```

## GitHub Pages

Проект можно публиковать как статический сайт из ветки `main`, папка `/root`.
